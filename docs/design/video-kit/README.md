# Original Figma storyboard

The [editable Figma kit](https://www.figma.com/design/4mdtod74gknaCCm8q1nrDj) holds the original storyboard, shared app components and motion studies. Its feature order guides the current [72-second native-footage intro](../../../launch-video/README.md).

The former 59-second production pipeline, generated snapshots, Blender breathing study and duplicate asset manifests have been retired. Their last complete source is preserved in [Git history](https://github.com/1vecera/Mluva/tree/35c1afb01bd27facc652fbeb4e5c8100ac0b9b26/docs/design/video-kit). The Figma file itself is unchanged.

The [canvas reflow helper](reflow-canvas.mjs) remains because the separate [logo study](../logo-study/README.md) uses it. Load the Figma use skill before running it through the Plugin API; it defaults to a dry run and applies changes only with `dryRun: false`. [Attribution](ATTRIBUTION.md) retains the original design sources and licensing.
