Scope: the native macOS app surfaces in macos/Sources/Mluva (menu bar panel, recording pill, F12 session wheel, History, Settings, Welcome, annotation ink). Mode: operate.

Audience and job: developers mid-task on a Mac who dictate into editors, terminals and running Claude Code sessions; press a function key, talk, and get out of the way. Constraint from Daniel (26 Oct 2026): the first build looked generic; give it its own character matching the spirit, not the styling, of the Omarchy version. Keep macOS 26 Liquid Glass and native controls.

## Direction contract

THESIS: Mluva is a drafting instrument made of glass. Words are set like measurements, keys are drawn as legends, and red is only ever the live signal or a mark you made. It refuses the rounded-capsule SwiftUI default: SF Pro chips, tinted glass pills, cards.

OWN-WORLD: graphite Liquid Glass for every floating layer, chalk text, hairline rules at 0.5-1 pt, JetBrains Mono for all authored text and numerals, keycaps as 1 pt outlined boxes with mono legends, one redline red (#E91B27 / #FF4048) for recording, selection arcs and ink. Windows follow system appearance with the same type and rules.

STORY: press F9, a title-block strip appears with the signal light, a mono REC timer and a live trace; words arrive in a ruled sheet above it; F9 again and it reports where the text went.

FIRST VIEW: the pill strip and the F12 dial: a protractor ring of minute ticks, sessions on leader lines with [A] legends, the chosen one joined to 12 o'clock by a red arc.

SIGNATURE: leader lines and the red redline arc, the same grammar the ink annotation uses on screen.

RISK: mono everywhere can read as a terminal costume; native controls, generous spacing and real hierarchy keep it a Mac app.

Raises from declined challengers: strict monochrome plus one red (datamatics); type and rules carry hierarchy, no cards (metro); status as a fixed mark ramp (star atlas); times right-aligned tabular against the margin (j-card); one thing owns the floating layer (feed); History text on a fixed reading measure (lexicon).
