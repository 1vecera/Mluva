# Pinned non-Python ASR data

Mel matrices and CUDA preprocessing graphs come from `onnx-asr` 0.12.0, the dependency used by the unchanged v1.6.0 comparison environment. Its public wheel has 3,980,006 bytes and SHA-256 `5e7ceca454609819ea7833f61e2302e0c8f6ece4f8a78b66c5daba53cb51de4a`. The installed reference files were compared byte for byte with that verified archive before collecting observations. The [upstream source](https://github.com/istupakov/onnx-asr) is MIT licensed; retain [its notice](onnx-asr-LICENSE) with this data and the derived native feature/decoder implementation when packaging.

`whisper80-mel.f32le` and `nemo128-mel.f32le` contain unchanged row-major little-endian float32 values from `preprocessors/data/fbanks.npz`, shaped `[201, 80]` and `[257, 128]`. The window files freeze the released NumPy Hann values: Whisper uses 400 float32 samples from the periodic window; NeMo uses 400 float64 samples padded to 512. This prevents a math-library upgrade from silently regenerating different coefficients. Sizes and hashes are recorded and checked in [the independent frontend fixture](../tests/fixtures/released-frontends.json).

`whisper80_conv.onnx` and `nemo128_conv.onnx` are unchanged CUDA preprocessing graphs from the verified wheel. Their respective SHA-256 values are `ee6096f815911e76b21e90b6ee126a99127efeadcc870805e2f5967f65af28da` and `5bbdc98847c3153c54e7b58f2c8668d0c19a22d07ed16204a058d26880985c6c`. They preserve the released GPU path; physical CUDA acceptance is still pending. No Python module, interpreter, converted Python helper or inference runtime library is embedded here.

CPU recognition explicitly uses the reference ONNX Runtime 1.30.0 native libraries. GPU support must retain the released 1.26.0 pin. `ort` is pinned to 2.0.0-rc.13 with API 26, dynamic loading and no automatic binary downloads. Public API calls require a separately verified native runtime and model directory; production provisioning and the provider/session owner remain pending. The runtime's full archive/member hashes are recorded in [the physical inference fixture](../tests/fixtures/released-onnx-inference.json).
